PASSO 5️⃣ : DEPLOY AUTOMÁTICO NO RAILWAY (5 min)

  1. Vá para: https://railway.app/dashboard
  
  2. Clique: "Create New Project"
  
  3. Selecione: "Deploy from GitHub repo"
  
  4. Clique em seu repositório: "brasil-doces-do-vale"
  
  5. Railway vai:
     - Detectar Node.js backend
     - Detectar Vite frontend
     - Provisionar PostgreSQL
     - Fazer build automático
     - Fazer deploy automático
     
     ⏳ Tempo: ~3-5 minutos
  
  6. Quando terminar (tudo ✅ verde):
  
     ✅ Backend: https://SEU-PROJETO-backend.up.railway.app
     ✅ Frontend: https://SEU-PROJETO-frontend.up.railway.app
  
  7. Copie essas URLs!

IMPORTANTE ⚠️  : CONFIGURAR VARIÁVEIS DE AMBIENTE

  No painel do Railway, vá em: "Variables" (colinha ao lado de Deployments)
  
  Clique: "Add Variable"
  
  Adicione ESTAS variáveis (uma por uma):
  
  ┌───────────────────────┬──────────────────────────────────────────┐
  │ Variável              │ Valor                                    │
  ├───────────────────────┼──────────────────────────────────────────┤
  │ JWT_SECRET            │ (gere uma aleatória — veja abaixo)       │
  │ STORE_WHATSAPP_NUMBER │ 5574813241266                            │
  │ STORE_PIX_KEY         │ sua-chave-pix@email.com (coloque a real) │
  │ PORT                  │ 3333                                      │
  │ CORS_ORIGIN           │ https://seu-projeto.up.railway.app       │
  │ NODE_ENV              │ production                                │
  └───────────────────────┴──────────────────────────────────────────┘
  
  ✅ Como gerar JWT_SECRET aleatório:
  
     Abra Node.js no terminal:
     $ node
     > require('crypto').randomBytes(32).toString('hex')
     'abc123def456...' ← Copie isso
     > .exit
  
  Cole o valor em JWT_SECRET!
  
  ⚠️  PostgreSQL:
      Railway cria automaticamente!
      Ele gera DATABASE_URL automaticamente
      Não precisa fazer nada!

🚨 TROUBLESHOOTING

  ❌ "GitHub não reconhece usuário"
     → Você está logado no GitHub?
     → Tente fazer logout e login novamente
  
  ❌ "Railway não encontra repositório"
     → Você autorizou Railway no GitHub?
     → Vá em GitHub → Settings → Applications
     → Autorize "railway-app"
  
  ❌ "Página em branco no site"
     → Verifique logs do Railway
     → Verificar se variáveis de ambiente estão corretas
     → JWT_SECRET foi configurado?
  
  ❌ "Admin não funciona"
     → Reloaded a página? (Ctrl+Shift+R)
     → Você usou admin/brasil2024?
     → Limpe localStorage
  
  ❌ "Checkout não abre WhatsApp"
     → Número WhatsApp está correto?
     → STORE_WHATSAPP_NUMBER=5574813241266
     → CORS_ORIGIN foi configurado?
     → Verifique logs do backend
