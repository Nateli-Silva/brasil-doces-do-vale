🆘 PROBLEMAS?

   ❌ "Não carrega a página"
      → Terminal ngrok ainda rodando? (Ctrl+C = para)
      → URL correta (https, não http)
      → Celular na mesma rede? (WiFi)

   ❌ "Admin não funciona"
      → Username: admin
      → Password: brasil2024
      → Reload a página

   ❌ "Página em branco"
      → Frontend rodando em terminal 2?
      → Backend rodando em terminal 1?
      → npm install completo?

   ❌ "Erro no checkout"
      → Você selecionou um horário de entrega? (obrigatório!)
      → Número WhatsApp correto? (+55 74 8132-4126)
